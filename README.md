# Investment Projects

A collection of investment research and quantitative finance projects — asset allocation strategies, portfolio analysis, financial modeling, and market valuation research.

## Projects

### [CAPE-Based Dynamic Asset Allocation](CAPE-Based-Asset-Allocation/)
Tested whether the Shiller CAPE ratio predicts future equity returns using 103 years of S&P 500 data (1922–2024), then built a three-tier valuation-based allocation strategy (80/20 → 60/40 → 30/70). Backtested 1933–2024: **9.14% CAGR vs. 8.56%** for a static 60/40 benchmark, with a slightly lower max drawdown.

![Portfolio Growth](CAPE-Based-Asset-Allocation/Portfolio%20Growth.png)

**Tools:** Excel, OLS Regression, Financial Modeling
